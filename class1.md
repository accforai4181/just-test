# 📦 Variables

Variable data store karta hai.

Syntax

```python

```

Example

```python

```

Output

```

```

# 🎯 type() Function

```python
name = "Ali"

print(type(name))
```

Output

```
<class 'str'>
```

---

Example

```python
print(type(10))

print(type(10.5))

print(type(True))
```

Output

```
<class 'int'>
<class 'float'>
<class 'bool'>
```

# ⌨️ User Input

User se data lene ke liye

```python
input()
```

Example

```python
name = input("Enter Your Name: ")

print(name)
```

Output

```
Enter Your Name: Ali

Ali
```
